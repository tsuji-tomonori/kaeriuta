# シナリオ進行表

## 全分岐フロー

`prologue → chapter1 → chapter2 → chapter3`

- 凶器を取る → `chapter4a` → A-1（推理失敗）／A-2（旧道＋低疑惑）／A-3（計画・生存証拠不足）／A-4（各系統の高水準所持）
- 少年の部屋の扉を叩く → `chapter4b` → B-3（察知50以上で標的化し、五番の夜に防衛失敗）／共同推理後 B-1（原題の意味）／B-2（それ以外）

各章末には「頁をめくる音」を置く。唄の読みは、一章で表の毒殺、二章で脚本のずれ、四章で律の告発と折句へ進める。

## 統合状態

シーンレジストリ、プロローグから第一章への遷移、`call`と各特殊パート、END遷移は統合済みである。以後の変更は `node tools/シナリオ検証.mjs` と `node tools/統合検証.mjs` で参照整合を確認する。

## アセット追加要望

顔なし死体、原稿、隠し部屋などは既存manifestのCG・背景で代用済み。頁めくり／タイプライター専用SEと手毬唄歌唱BGMは未登録のため、追加時は `se_page`、`se_typewriter`、`bgm_temariuta_vocal` を希望する。

## 立ち絵の舞台設計

栞は一人称視点のため原則として立ち絵に出さない。例外は、第四章A冒頭で鏡に映る自分を直視する場面と、第四章Bで宗玄と原稿を挟んで対峙する場面だけとする。大人数の場面では、現在の話題の中心にいる三人だけを舞台へ残す。
