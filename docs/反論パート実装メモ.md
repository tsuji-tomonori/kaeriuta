## 二本のゲージ

`gazeValue({ overknow, suspicion }) = clamp(round(overknow × 45 + suspicion × 0.1))`。
知りすぎは支配的で、疑いは補助的な項である。

| overknow | suspicion | 注視 |
| ---: | ---: | ---: |
| 0 | 0 | 0 |
| 0 | 100 | 10 |
| 1 | 0 | 45 |
| 1 | 50 | 50 |
| 2 | 0 | 90 |
| 2 | 20 | 92 |

決着では悟郎の推理とコウナンの注視を同じ重さで並べる。`conan_marked` は「推理には勝った。しかし、あなた自身を見抜かれた」と明示する。`resultFor(conviction, overknow)` の判定条件と戻り値は変更していない。

## 応答の対応

表示用リストは全応答の元インデックスを `data-r` に入れる。未所持の札も同じ場所に disabled button として残し、クリック可能なボタンは `node.responses[Number(data-r)]` を直接参照する。したがって未所持札によって配列が詰まっても、効果の対応はずれない。

効き目は確信度の変化から三段階で表示し、代償は知りすぎ・良心・信頼・疑いの各変化を具体的に表示する。札にメタデータがあれば取得元も併記する。

## 実ブラウザ確認手順

1. 第二章の尋問で、未所持の「配膳の当番メモ」などが灰色で見え、取得元・効き目・代償が読めることを確認する。
2. 知りすぎる反論を二回選び、悟郎の確信が低くても「コウナンの注視」が危険域となり、決着でねじれの文が出ることを確認する。
3. 第四章Aの尋問で、所持した偽アリバイ札に第一章の取得元が表示され、disabled な札を挟んでも選択結果が意図した反論に対応することを確認する。
