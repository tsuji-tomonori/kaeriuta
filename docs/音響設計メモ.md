# 音響設計メモ

## 変更範囲

`tools/音源生成.sh`、`assets/audio/**`、`assets/manifest.json`、音声エンジン／設定、担当シナリオ、担当テストのみを編集した。DOM契約の変更はない。

## 主題

「帰り唄」動機は **D5–F5–E5–C5–D5–A4–G4–D5**（各1秒、終止D5のみENDINGでは2秒）。最後のD5を省く到着曲、低域へ移す館内曲、一音を欠く尋問曲、半拍化する推理曲を同じ `melody_layer` ヘルパから作る。六番「まことの筆で閉じましょう」に対応し、最後のD5が初めて鳴る真相曲で解決する。

END専用曲は3曲: 逮捕（D5–F5–E5–C5で断絶）、脱出（未終止を遠い笛／風として残す）、救済B-1（長調寄りのD5終止）。他4ENDは `bgm_ending` を共用する。

## 3層

BGMは旋律・和音、`amb_*` は独立ループ、`se_*` はワンショット。環境音音量は保存設定・設定画面・`AudioManager.playAmbience/stopAmbience` でBGMと別にフェードする。主な配置は外観雨、ホール、廊下、隠し部屋、嵐。

未配置（シナリオ上の該当背景がない／今回未到達）: `bg_library_day`→`amb_library`、`bg_kitchen`→`amb_kitchen`、`bg_basement_anteroom`→`amb_basement`。`bg_hall_morning` は `amb_hall` に対応する。検証器は `amb` を未知型として拒否しない（asset存在も現行検証では確認される）。

## SE照合

`chapter1:5` の銀盆は `se_tray` へ修正、`chapter1:91` のタイプライターは `se_typewriter` へ修正。既存SEは、glass（湯呑の割れ）、door（封鎖・扉）、footsteps（廊下）、thunder（遠雷）、clock（時計）、paper（頁・紙）で本文と整合する。手毬SEは素材登録済みだが、物語中の追加配置は未実装。

# 音響改修（2026-07-27）

`melody_layer` は各音を基音 + 第2倍音（40%）+ 第3倍音（19%）+ 第4倍音（9%）とし、倍音ほど速く減衰させる。さらに25msの高域ノイズ・アタックを混ぜ、単一正弦波ではなくオルゴール／ピアノ寄りの打鍵にした。SEは2パス `loudnorm` の後、エンコード済み音を再測定して固定ゲイン補正する。

- reasoning: `D5 F5 F#5 E5 C5 D5 A4 G4 D5`
- rescue: `D5 F#5 E5 C5 D5 A4 G4 D5:2`
