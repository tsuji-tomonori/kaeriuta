11ペルソナの実ブラウザ通しプレイを再実行したうえで、物語・システム・体験の3観点を分担評価し、その結論をここへ束ねる。

- 計測の土台: `tools/AIプレイ/実行.sh all` を再実行（11/11 完走、`errors: []`、到達ENDは基準線と全一致、7END全踏破）

## 1. 結論

**面白い。ただし「面白さの中心にあるはずの駆け引き」が、実装上いくつか空回りしている。**

読み物としての完成度は高い。倒叙の主人公を「事実を知ったまま初見の反応を演じる司書」にした設計が、館ミステリの探索を〈情報を得る快感〉と〈得たと悟られる怖さ〉の二重構造に変えている。本文41,971字・588ノード（実測）で、1周およそ65〜80分。7ENDは色違いではなく、A系＝罪の引き受け方の4種、B系＝真相の返し方の3種として書き分けられている。

一方、看板である「反論するほど見抜かれる」は、**第二章の実データ上、ジレンマになっていない**（後述 2-1）。手毬唄ボードは**11通りのプレイすべてで同じ最低スコアのまま退席されており、ゲームとして機能した記録が一件もない**（後述 2-2）。8つのパラメータのうち良心・語り手・動揺は結末条件に一度も参照されない。つまり「盤面は豪華だが、勝敗に効いている面が思ったより少ない」状態にある。

現状を一言でいえば、**読み物として9、ゲームとして6**。優先すべきは新規要素の追加ではなく、既にある駆け引きを実際に効かせることである。

## 2. こちらで独立に実測して確定した欠陥

分冊の指摘とは別に、実プレイ計測とコード照合から確定した3点を挙げる。いずれも静的検査は全て通る種類の欠陥である。

### 2-1. 第二章の反論データが二重化しており、看板のジレンマが消えている【最優先】

`src/systems/rebuttal/index.js:35` は `src/data/parts/rebuttal-ch2.js` を読み込むが、続く36行目で `args.nodes` があればノード単位で上書きする。第二章は `src/data/scenario/chapter2.js:48` でインライン定義を渡しているため、**実際に遊ばれているのはインライン側であり、`parts/rebuttal-ch2.js` の設計はほぼ死にデータである。**

|論点|`parts/rebuttal-ch2.js`（死）|`chapter2.js:49-51`（実際に遊ばれる）|
|---|---|---|
|N1「毒は寝酒では？」|知りすぎ+1、疑い+15|知りすぎ+1、疑い+15、**確信+5**|
|N2 の選択肢数|5択（読書記録／藤乃へ転嫁を含む）|**3択**（両方とも存在しない）|
|N2 剛蔵へ転嫁|確信-20、**信頼-1**|確信-20、**良心-1**|
|N3 沈黙|確信+15（N2撃破済みなら0）|**効果なし（完全に無料）**|

実装上の帰結が重い。**「真実を知っているからこそ言える一手」が、確信度を下げるどころか+5して、さらに知りすぎ+1・疑い+15を背負う純粋な罠になっている。**得がゼロなので、プレイヤーは迷わない。設計意図（`parts` 側に `designIntent: '正しい知識を使うと死ぬ。「知らないフリ」の基本文法を教える。'` と明記されている）が、実データでは「知識を使う理由が最初から無い」に反転している。同時に N3 の沈黙が無料なので、第二章の最適解は「札があれば出す、無ければ黙る」だけになる。

なお、この二重化は `評価-システムと駆け引き.md` の実測表の「反論・第二章」行にも影響しており、あの行は死にデータ側の数値である（第四章Aはインライン上書きが無いので正しい）。

**対処**: ①どちらを正本にするか決めて片方を消す（インライン側を残すなら `parts/rebuttal-ch2.js` は削除、逆なら `chapter2.js` の `nodes` を落とす）。②そのうえで N1 の危険な反証に「確信を大きく下げる」見返りを与え、N3 の沈黙に代償を戻す。③同種の上書きが他に無いか、`args.nodes` を渡している呼び出しを洗う。

### 2-2. 手毬唄ボードは、11通りのプレイすべてで同一の最低スコアのまま終わっている【最優先】

11ペルソナ全員が、**操作14回・見せる盤の説得力 1/6・まことの盤とのズレ 0・正確さ 0/6** で退席している。ペルソナの性格（完全主義の推理者から、わざと下手に遊ぶライト層まで）に一切依存せず、結果が完全に同一である。

```
suiri … danzai  board観測=14  最終(説得/ズレ/正確)=[1,0,0]  最大説得=1  最大正確=0   ← 11体すべて
```

意味は二つある。

- **ゲーム側**: 説得力1/6 の効果は確信-4、正確さ0なので旗もなし。**この盤は現状、全プレイで確信度を4下げるだけの装置**であり、分岐に寄与していない。`canPlaceBoardCard()` は種別不一致でも配置を止めず、未記入のまま「盤を伏せて席を立つ」でいつでも抜けられるため、解かないことの代償もない。
- **測定側**: AIプレイ基盤はこの盤を操作できていない（先頭カードを掴んで置くだけ）。つまり**手毬唄ボードの面白さは、11ペルソナ体制で一度も測れたことがない。**設計の良し悪し以前に、評価の死角になっている。

**対処**: 盤のルールを締める（見せる盤は確定時に全欄必須、種別違いは置く前に警告）と同時に、**AIプレイ側に「カードの種別と欄の種別を合わせて置く」最低限の推論を入れて、この盤が測定対象に入る状態を作る**こと。ゲーム側だけ直しても、直った証拠が取れない。

### 2-3. 無操作で送り続ける区間が、開幕と第三章にある

ログ見出しの連続 `advance` から実測した（文字送りの二重記録は2で割って換算）。

|区間|連続する本文ノード数|
|---|---|
|起動〜最初の選択「宴の席、どこに座る？」|約36ノード（step 1〜72）|
|プロローグ後半〜第一章の最初の選択|約46ノード（step 121〜213）|
|第三章 岐路（分岐の手前）|約36ノード（step 474〜546）|
|第四章B 五番の夜|約49ノード（step 622〜）|

文章の質は高いので「退屈」ではないが、**最初の意思決定まで36ノード**は、ライト層を取りこぼす長さである。プロローグ内に軽い選択（栞の記録癖を1回使わせるだけでよい）を1つ前倒しすると初速が変わる。第三章の36ノードは分岐直前の助走なので、分冊（物語）が指摘する「内省の圧縮」と同じ処方が効く。

## 3. 分冊からの主要指摘（検証済みのもの）

引用の原文一致と数値のコード照合をこちらで実施し、通ったものだけを挙げる。

- **END B-3 の日付が矛盾している**（物語）。分岐元 `chapter4b` は「第四章B　3日目」だが `end_b3` の章表記だけ「エピローグ　**2日目**・深夜」。他6ENDはすべて3日目。→ `3日目・未明` へ統一。**修正コストが最小で効果が明確なので、真っ先に直してよい。**
- **良心・語り手・動揺は、どのEND条件からも参照されない**（システム）。`src/data/scenario/` 内で `conscience` が現れる6箇所はすべて effects 側で、cond 側は0件。使わないなら章末サマリの性格記録へ統合し、パラメータ数を減らすほうが読み手に誠実。
- **自由行動の「代償」表示と実際の適用値が食い違う**（システム）。数値を読んで最適化するプレイヤーほど裏切られる。効果定義を一箇所に集約し、表示文を同じ定義から生成する。
- **B-2 は宗玄の死が場面外で起き、断罪を選んだ栞の能動性が回収されない**（物語）。7ENDの中で唯一、劇として弱い。
- **共同推理に失敗圧がない**（システム）。カード不足はボタンが無効になるだけで、他の手段を選べば進む。11ノードの詰め将棋を完走する作業になりやすい。
- **本文41,971字・588ノード、215字超のノードは0件**（体験）。こちらでも同一の数値を再現した。メッセージ窓の固定寸法制約は現状守られている。CIへ入れて維持する価値がある。

## 4. 優先順位

|順|項目|理由|
|---|---|---|
|1|END B-3 の日付統一|一行で直り、没入を切る明白な矛盾|
|2|第二章の反論データの二重化を解消し、危険な反証に見返りを与える|看板の駆け引きが機能していない。修正しないと他の調整が全部その上に載る|
|3|手毬唄ボードのルール強化＋AIプレイ側の操作改善|唯一「測れていない」パート。測定基盤ごと直さないと直った確認ができない|
|4|自由行動の表示と実値の一致|信頼を損なう不整合。定義の一元化で恒久的に解ける|
|5|プロローグに選択を1つ前倒し／Bルート終盤の内省を圧縮|初速と着地の両端のテンポ|
|6|良心・語り手・動揺の去就を決める|使うか畳むか。宙吊りが一番よくない|

## 5. 測定の健全性について

今回の再実行では11ペルソナ全員が `status: "ended"` かつ到達ENDが基準線と完全一致し、7END全踏破も維持されていた。直近のUI改修（メッセージ窓の固定寸法化・自由行動の部屋モーダル化）による検証基盤の退行は起きていない。

ただし 2-2 のとおり、**手毬唄ボードだけは「完走している」が「遊べていない」**。基準線が緑であることは、全パートが測れていることを意味しない。
