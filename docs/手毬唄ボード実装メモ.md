## 二層の盤と判定表示

画面上部の「まことの盤」と「見せる盤」は、button のキーボード操作可能なタブで切り替える。どちらにも死者・実行者・意味の欄と、日本語名・注記付きの札が出る。下部には常に、見せる盤の説得力、二面のズレ、まことの盤の正確さを並べて表示する。

配置操作は「どの札をどの欄へ置いたか」という中立文だけを返し、正誤を明かさない。全欄を埋めて確定した時点で、矛盾している全欄の文をまとめて返す。矛盾文に挙がらなかった欄は正しいと確定できるため、推理型ペルソナは verified の欄を保護し、失敗した組合せを除外して「確定 → 矛盾欄の差し替え → 再確定」へ収束する。矛盾ゼロの確定後にだけコミットし、盤の効果を受け取る。

見せる盤の説得力は確信を下げる。二面のズレは awareness を上げ、まことの正確さは overknow を上げる。従来の一致数ログと閾値での `other_scriptwriter_noticed` は、まことの盤を基準に維持する。

## 実装上の判断

呼び出し側の `args.verses` がある場合は、その number の番のみを出す。欄と種類が違う札は一度目に警告し、同じ欄をもう一度押せば仮説として置ける。選択中の札を再度押すと札を戻せる。未確定でも「盤を伏せて席を立つ」で終了できる。

進行ドライバは commit-close を自動クリックせず通常候補としてペルソナへ渡す。非推理型にも確定後のコミットを高く採点し、従来の「確定して効果を受けて退席」を維持する。推理型は未解消矛盾がある間、確定とコミットを抑制する。

## 総当たり耐性

`tools/AIプレイ/総当たり耐性.mjs` は固定シードで第二章の先頭二詩、配布札、初期配置、200操作上限を再現する。矛盾文を読まないランダム個体が 6/6 に届かない否定側と、確定時の矛盾欄だけを排除する個体が 6/6 に届く肯定側を同時に固定する。DOM やブラウザを使わず、ゲーム側の配置・配置可否・確定・採点関数を通す。測定死角検査からも呼び出し、実ブラウザ結果とは独立して単体実行できる。

## 実ブラウザでの確認手順

第二章の談話室で手毬唄ボードを開く。一番・二番だけが表示され、札は「恩田徹」などの作中名で見えることを確認する。見せる盤で札を置き、「この仮説で確定」を押して矛盾文または金色の独白を確認する。まことの盤へ切り替えて別の配置を作り、三つの判定値が変わることを確認する。最後に空欄のままでも「盤を伏せて席を立つ」で進行できることを確認する。
