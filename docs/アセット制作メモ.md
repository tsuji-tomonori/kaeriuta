# アセット制作メモ

## 制作方針

- image-gen の組み込み生成を使用する。生成物は manifest の指定パスへ配置する。
- 背景は人物なし、中央から下部に立ち絵を重ねられる余白を確保する。
- 既存作品・実在人物・既存作品の画風は参照しない。探偵側も役割に基づく完全オリジナルの外見であり、固有の衣装・小物・名称を使わない。README の権利・画像方針を確認済み。

## 共通スタイルプロンプト（試作確認後に確定）

昭和末期〜平成初期の日本、豪雨で吊り橋が落ち孤立した山峡の和洋折衷別荘（大正〜昭和初期建築）。沈んだ暗色基調、灯火・行灯・暖炉の鈍い橙色の点光源と冷たい青灰色の闇の対比、低彩度。手描き風デジタルペイント、粒状のテクスチャ、和紙のように沈む質感。写真的ではなく、フラットなアニメ塗りでもない。静かな不穏、人の気配が消え誰かに見られている感覚。文字・ロゴ・透かしなし。

試作 `bg_mansion_exterior_rain` を確認し、雨の粒子、青灰の闇、窓の鈍い橙、建築の手描き感が本作に適合すると判断した。この記述を以降の背景・スチルで共通基調として使用した。

## 追補（表情差分14点の半透明回帰修正）

- 原因は、表情差分14点のクロマキー処理で背景色との色距離だけを用い、`inner=165` / `outer=240` の広い範囲をアルファ化したこと。これにより、マゼンタに近い藤乃の葡萄色ワンピースだけでなく、宇野・剛蔵などの衣装／肌の中間色まで背景と誤認して半透明になった。
- `tools/透過処理.py` は、外周から4近傍で連結しているキー色候補だけをフラッドフィルで背景として扱う方式へ変更した。人物の内側でキー色に近い画素は不透明に保持する。半透明化はこの外周背景のアンチエイリアス帯に限り、デスピルはRGB補正のみでアルファを下げない。
- 対象14点（観察者3、宇野2、佐伯2、剛蔵3、藤乃2、同行者2）は、保全済みの原本を使って構図統一を再適用し、修正済み透過処理で輪郭を再デスピルした。表情・人物像は再生成していない。元のマゼンタ背景生成画像も `~/.codex/generated_images/019f9d1d-bc04-7dc1-b0a0-04ab92d41595/` に存在することを確認した。
- `tools/透過検品.py` は全立ち絵について、可視画素の平均α、完全不透明率、輪郭から5px収縮した内側領域の平均α、輪郭紫、700×1200 RGBAを必ず検査し、いずれかが不合格なら非ゼロ終了する。基準は内側平均α≧250、完全不透明率≧95%、輪郭紫0px。既存の健全点（探偵normal、佐伯guarded、恩田wary、トヨnormal）は内側平均α255.0、完全不透明率97.8%／98.5%／98.0%／97.1%で基準を満たすことを確認して確定した。
- 修正前は14点が内側平均α64.3〜131.5、完全不透明率0.8〜26.4%（藤乃normalは113.0／3.5%、宇野normalは138.5／0.8%）だった。修正後は全33点が合格し、対象例は藤乃normal 251.7／96.7%、宇野normal 250.2／95.9%、同行者kind 250.5／96.5%、佐伯pale 250.3／96.0%（順に可視平均α／完全不透明率、内側平均αはいずれも254.9以上）。
