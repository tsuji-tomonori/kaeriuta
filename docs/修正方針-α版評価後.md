## 0. 方針の骨子

**新要素を足さない。既にあるのに効いていないものを効かせる。**

α版の弱点は機能不足ではなく、〈設計意図は書かれているのに、実データがその意図を裏切っている〉種類の欠陥に偏っている。反論の二重定義、到達不能な閾値、表示と実値の乖離。いずれも静的検査を全て通り抜けるため、**「直した」を実測で確かめる手順を各波にセットで入れる**ことを方針の中心に置く。

文章の改稿（テンポ・B-2の演出）はゲーム側の欠陥を直してから着手する。順序を逆にすると、数値の調整で本文の意味が変わり、二重に書き直すことになる。

### D-1. 第二章の反論、どちらを正本にするか　→ **案A（parts側を正本）で決定**

### D-2. 危険な反証（知りすぎ札）に見返りを与えるか　→ **推奨どおり見返りを与える**

現在の N1「毒は寝酒では？」は、実データで **知りすぎ+1・疑い+15・確信+5**。得がゼロの純粋な罠で、迷いが発生しない。parts 側でも確信は動かない（±0）。

推奨: **確信を大きく下げる（-15前後）代わりに知りすぎ+1・疑い+15を負う**形へ。「使えば通るが、コウナンに個別マークされる」という看板どおりの取引にする。あわせて N3 の沈黙が実データで無料になっている点を、parts 側の +15（N2撃破済みなら0）へ戻す。

### D-3. 手毬唄ボードの「札の種別」ゲートをどうするか　→ **案A（`kinds` 配列化）で決定**

**注意: 分冊（システム）の優先度高「カード種別違いは置く前に警告する」を、そのまま実装してはいけない。** 正解18枠のうち5枠が種別不一致だからである。

```

3番のactor = sogen（札の種別は dead）
5番のdead  = shiori（札の種別は actor）
5番のactor = sogen（札の種別は dead）
6番のactor = sogen（札の種別は dead）
```

宗玄は「死者でもあり実行者でもある」、栞は「実行者でもあり五番の死者でもある」——これは作品のテーマそのものなので、**正解の側が正しく、`kind` 単数の設計のほうが間違っている**。

|案|内容|評価|
|---|---|---|
|**A（推奨）**|`boardCards[].kind` を配列 `kinds` にし、`canPlaceBoardCard()` を包含判定へ。宗玄に `['dead','actor']`、栞に `['actor','dead']` を与える|テーマと整合し、警告を安全に出せるようになる|
|B|種別ゲートを廃止し、矛盾文だけで導く|実装は最小だが、初見の導線が弱いままになる|

### D-4. 良心・語り手・動揺を使うか畳むか　→ **α版では畳むことで決定**

3つとも END 条件から一度も参照されていない（`src/data/scenario/` 内の `cond` 側ヒット0件）。

推奨: **α版では畳む**。章末サマリの性格記録へ統合し、パラメータ表記を5つに減らす。使い道を作るのは β 以降の設計課題として切り出す。宙吊りのまま残すのが一番よくない。
