# α版リリースノート

『帰り唄 ―手毬唄の館―』α版は、プロローグから第四章までと全7ENDを通して遊べる状態である。音声と一部の画像差分は継続制作中だが、欠落アセットはCanvasプレースホルダで安全に表示する。

## 公開

公開版は <https://tsuji-tomonori.github.io/kaeriuta/> で利用できる。GitHub Pagesで`main`ブランチのリポジトリルートを配信し、`assets/chara/_原本/`を含む`_`始まりのディレクトリをJekyllに除外されないよう、リポジトリルートに`.nojekyll`を配置している。

GitHub Pagesの配信はCIテストではない。GitHub Actionsを含むCIは未設定であり、検証契約の正本はローカルで実行する検証コマンドである。

## 発見・修正した主な不具合と設計上の矛盾

- 統合の繋ぎ目: シーンレジストリ、プロローグから第一章への遷移、`call`と特殊パートのeffects・END遷移を結線した。
- END本文: 未所持の証拠や人物名を断定する文章を条件分岐化し、`requires`と未所持時の本文を対応させた。
- 隠しEND: A-4を三核心証拠と系統条件、B-1を折句・共同推理・計画書条件へ結び、B-3の察知閾値を実到達可能な50へ調整した。
- 終盤の選択: END名を直接選ぶメニューを、割り込み・逃走・沈黙・反論という行動選択と機械分岐へ置換した。
- 反論: 同一構造だった本戦を7ノードの固有主張・固有代償・カード要件へ再設計し、沈黙・転嫁・危険な反証の差を作った。
- 手毬唄: 第四章Bの五番二行目を正典の「りょうしの鉄砲」に統一し、折句は「仕込んだ律」と「読んだ栞」を明確に分離した。
- 死体選択: 顔／退避を選んだ直後に手元を見た前提の会話が出る矛盾を分岐で修正した。
- 表示・進行: stageのクリック送り、自由行動の本文→次行動遷移、特殊パートの完了経路、長文スクロール、未定義値表示を修正した。
- 立ち絵: マゼンタ縁は全画素検査とデスピルで再検品し、構図混在は頭部比率・余白を揃え、クロマキー起因の半透明化は外周連結背景だけを抜く方式へ修正した。

## 既知の残件

- 音声・BGMの完成版は未実装。
- 特殊パート途中のセーブ／再開は不可。完了後は通常どおり保存できる。
- 一部の背景、CG、立ち絵表情差分はプレースホルダまたは継続制作対象である。
- 同行者・観察者などの残る表情差分は、画風と人物性の統一を続ける。
- 実ブラウザ検証・AIプレイはChromeを必要とする。結果確認は起動可能なオーケストレーター環境で行う。
