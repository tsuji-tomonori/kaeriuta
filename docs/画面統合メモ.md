## 実装概要

- 発言者は `brightness(1.08)` と `saturate(1.07)`、非発言者は `brightness(.62)` と `saturate(.66)` にして、明度と彩度の双方で読み分ける。
- 人物スロットの足元に、現在の章色を `--environment-glow` として用いる薄い環境光を重ねる。
- 背景だけに `blur(.5px)` と `brightness(.975)` をかけ、背景美術の細部を残したまま人物との距離を付ける。
- CG表示時は保持中の立ち絵をUI層で一時退場させ、次の背景切替でCGを解除して立ち絵を復帰する。シナリオデータと `main.js` は変更していない。
- グレーディングは `#cg-layer::after` の `pointer-events:none` な一枚のオーバーレイで行う。z-indexは立ち絵・メッセージ枠・HUD・選択肢・モーダルより下なので文字を濁さない。

# CG復帰・グレーディング確認（2026-07-27）

CGは背景切替時に加えて、`character-layer` の `show()` が次の明示的な立ち絵を表示する直前にも解除する。第二章では `cg_faceless_body` の次、同章8ノード目の `{t:'chara', id:'fujino', ...}` で立ち絵が復帰する。

グレーディング確認はURLに `?grade=ch3` を付ける（例: `http://localhost:8080/?grade=ch3`）。許可値は `prologue`、`ch1`〜`ch4b`、`rescue-end`、`ruin-end`。指定しなければsceneIdによる従来判定のままであり、オーバーレイは `pointer-events:none` のままである。
