# 実装メモ

- パラメータは初期段階の調整可能な提案値として、0〜100系と関係性の-10〜10系に分離した。詳細はデータ仕様を正とする。
- 条件は文字列式を禁止し、JSONデータを再帰評価する。シナリオ担当がJavaScriptを混ぜずに済み、`node:test` で検証できるため。
- manifestの画像は存在確認後に使い、欠けている間はCanvasプレースホルダへ必ず切り替える。アセット生成波が空ディレクトリのまま進めてもゲームが落ちない。
- `choice.goto` は専用の `{t:'label', id}` を参照する。`stage` は常に演出表示であり、アンカーとの兼用を禁止した。実行位置は `executionStack` に保存し、`if` を分岐配列のフレームとして処理するため、シナリオ定義を変更しない。分岐内セーブもこのスタックをそのまま往復する。
- プロローグ末尾は `chapter1` への `jump` として統合済みである。シーン参照・ラベル・特殊パートIDの不整合は `node tools/シナリオ検証.mjs` で検出する。
- 特殊パートは実装・`call`結線済みで、終了時に返すeffectsを共通の状態更新へ適用する。入力・出力の状態契約はデータ仕様を正とする。

## 画面表示改修

- 立ち絵は人物IDではなく `left` / `center` / `right` の位置をキーとする純粋状態遷移にした。同じ位置への `replace` は必ず前の人物を置換し、`fadeOut` はその位置を空にするため、重複表示は構造上起きない。
- 背景ノードでは立ち絵を全消去する。全シナリオの背景切替は、食堂から廊下・自室・大広間など場所または時間帯を移す場面転換であり、切替後に必要な人物は続く `chara` ノードで再表示される。人物を残すべき同一場面内の背景差し替えは確認できなかった。
- バストアップ立ち絵は `bottom:-17%`、`height:108%`、`object-fit:cover`、`object-position:center bottom` とし、切断済みの腰位置を画面下へ逃がす。16:9の基準画面と、レターボックスが維持するおよそ4:3〜21:9のビューポートで、顔がメッセージウィンドウより上に残ることを意図した。3人は各34%幅を `0% / 33% / right:0` に割り当て、顔の横方向の重なりを避ける。
- 演出文は上部の専用帯を使わず、通常文と同じ下部メッセージウィンドウにモノローグ枠で表示する。通常の台詞・モノローグ・演出だけに右下の「次へ」ボタンを出し、選択肢、特殊パート、ENDでは出さない。ウィンドウ全体のクリック送りも維持する。

## ゲーム本体へのUI結線

- `src/main.js` の `initializeApp()` がタイトル表示とdocument単位のキー／ホイール入力を所有する。再初期化時は前回の入力リスナとゲームセッションを破棄してから登録し直し、タイトル→ゲーム→タイトル→ゲームでも多重登録しない。
- ゲームセッションは `createScreen()` が作った画面を土台に、HUD、メッセージ、選択肢、立ち絵、手帳、バックログ、再生制御を一度だけ生成する。タイトルへ戻る際は再生タイマーと各オーバーレイを閉じ、非同期の特殊パートが遅れて完了しても破棄済みセッションへ反映しない。
- シナリオの実行位置は従来どおり `executionStack` が正である。既読キーは最終フレームから `path.join('.') + '#' + index` で作り、本文表示直前に記録する。台詞・モノローグ・ト書きは同時にバックログへ積む。
- クリック送りのタイプライター制御は `message-window` が所有する。全文表示済みのクリックだけが `main.js` の手動送りへ届く。Space／Enterは同じ手動送りへ集約し、表示途中なら全文表示だけを行う。スキップ／オートのタイマー経路は別の自動送りへ入り、表示途中ならまず全文表示してから次のタイマーを待つ。
- `playback` は既読スキップとオートのモード・タイマーを所有し、HUDは表示状態だけを受け持つ。選択肢、特殊パート、END、セーブ／ロード、確認、手帳、バックログの前には再生を停止する。
- 章頭へ新規遷移した時は `chapterSlot(sceneId)` の専用スロットへ状態を保存し、進捗の `chapters` に到達時刻とスロットを記録する。通常セーブや章頭セーブをロードして開始した場合は、ロード時刻で章頭スナップショットを上書きしない。
- ENDでは到達進捗と既読を永続化し、オートセーブを更新する。END表示にはタイトルへ戻る選択肢を併設する。背景とCGはいずれも `setBackground()` を通し、トランジションと二層入れ替えを共用する。
