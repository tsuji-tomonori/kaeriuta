# 立ち絵人物固定メモ（最終波）

## 結果

`makabe/uneasy` は候補の青キー原画から再処理した。`透過処理.py` は輪郭から内側
7px の HSV キー域（H=.62〜.93、S>=.30）を検出し、近傍の不透明画素の色相へ寄せる。
近傍もキー域の場合は、輝度を保って彩度を .26 まで落とす。アルファ値は変更しない。

| 画像 | 輪郭キー色域（改修前→後） | 同一性（後） |
|---|---:|---|
| makabe/uneasy | 3,832/26,828 (14.28%) → **5/26,833 (0.02%)** | IoU .901 / 髪 13.9 / 服 8.0 / 肌 17.3 / 頭 .008 / 肩 .034 / 顔MAD 33.59 |
| makabe/normal（比較） | 761/32,102 (2.37%) | — |
| shiori/normal（比較） | 732/29,407 (2.49%) | — |

改修前の真壁は依頼者測定では 930/2,920 (31.85%) だった。ここでは検品器と同一の
「不透明領域の外周から内側7px」定義で再測定しており、分母は異なるが、同一の HSV
域に対して 14.28% から 0.02% へ低下した。採用品とのアルファマットは完全一致した。

## 検品器の再較正と既存33点

`透過検品.py` は輪郭帯（アルファ境界から内側7px）の HSV キー色域を
**H=.62〜.93、S>=.30、V>=.35** とし、その率が **3%超** のとき不合格とする。V は
RGBを0〜1へ正規化した値で判定する。また、HSVのこの色相範囲は赤優勢の紫・マゼンタも
含むため、**B>R（青優勢）**をキー由来の追加条件とした。

藤乃2点が4%台になったバグは、後者の青優勢条件がなく、V>=.35を満たす紫ドレスの
明るい陰影まで「青キー色」として数えていたことだった。0〜1/0〜255の取り違えでは
なく、明度下限だけでは紫衣装を区別できないという判定条件の適用漏れである。修正後は
`fujino_normal` が7/27,269px（0.03%）、`fujino_uneasy` が10/27,784px（0.04%）となり、
いずれも合格する。`makabe/uneasy` は 4/26,833px（**0.01%**）で合格した。

### `sogen_shadow` の判断

現作業ツリーで 1,946/31,233px（**6.23%**、独立実測約6.3%）。該当画素は紺ビロードの上着、特に襟・肩・
袖の明るい反射と縁取りに連続しており、純青キーの残りではない。目視でも透明背景との
境界だけに偏在せず、衣装の陰影・ハイライトとして成立しているため、**正当な衣装色の
既知例外**としてファイル名で登録した。改修前の検品でも同じ6%台であり、今回の検品改修で
増えたものではない。画像は変更していない。

### 実行時の差異

既知の不良候補 `_候補/chara_makabe_uneasy_01_青キー透過.png` も明示的に単体検品した。
修正後も 2,582/26,833px（**9.62%**）で3%を超え、例外登録の対象外なので不合格（終了
コード1）となることを確認した。これは不良候補を検品対象に渡しても落とせることの確認で
あり、候補画像は変更していない。

## 色調和

`sogen/shadow` は色調和を適用した。作業ツリーの改修前実測では肩幅 .104（指示書の
.068 とは異なる）であり、RGBのみを変える処理ではこの値を直せない。`--allow-partial`
はこの不変の未達を隠さず、色指標を満たす最小率を二分探索して出力するための明示的
オプションである。

| 対象 | 補正率 | IoU / 髪 / 服 / 肌 / 頭 / 肩 / 顔MAD | bbox平均輝度 |
|---|---:|---|---:|
| sogen/shadow 改修前 | 0% | .850 / 59.5 / 19.3 / 30.3 / .015 / .104 / 40.37 | 47.00 |
| sogen/shadow 改修後 | **30%** | .850 / **41.9** / 13.6 / **21.0** / .015 / **.104** / 38.51 | 45.63 (-1.37, -2.9%) |

暗さは残り、顔帯MAD下限 13.29 も維持した。ただし肩幅 .104 > .09 のため全指標は未達。
`sogen/speech`（IoU .743）と `uno/kind`（IoU .816、肩 .094）は改修前のまま未達である。
`detective/sleepy` は全指標合格のまま、疲れた血色と乱れ髪を守るため色調和を適用しなかった。

## 検証と集計

- `python3 tools/構図検査.py`: 合格（平均28.2%、最小26.2%、最大28.6%）。
- `python3 tools/立ち絵同一性検査.py`: 真壁・探偵は合格。宗玄shadow/speech、宇野kind、栞resolveの4点は不合格。
- `python3 tools/透過検品.py`: `sogen_shadow` は登録済み既知例外、他の33点は合格
  （終了コード0）。

今回の重点5点は **2点達成（makabe/uneasy、detective/sleepy）／3点未達
（sogen/shadow、sogen/speech、uno/kind）**。透過検品は青優勢条件を含めて再較正済みで、
既知例外を除く33点は合格である。
