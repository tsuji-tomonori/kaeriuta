# 特殊パート実装メモ

## 実装済み

- `rebuttal`: 第二章尋問のN1〜N3と証言ログチュートリアル、第四章A本戦7ノード。確信度・知りすぎ・良心等をeffectsで返す。
- `jointReasoning`: 4フェイズ全11ノード、動揺閾値、代行、遺品倍加、開き直り、宇野同席、N10のB-2固定、六番選択、A-4自白補正。
- `freeAction`: 章ごとのブロック消費、決定的リスク、選択した実シーンへの`dispatches`返却。
- `temariBoard`: 六番×死者/実行者/意味、クリック貼付、正答・ズレの表示、三重の読み段階。
- `notebook`: 証言ログ、矛盾の赤表示、三系統フラグと証拠一覧。`installNotebook(ctx)`で右下ボタンとNキーを追加する。

## 統合状態

```js
import { parts } from './systems/index.js';
// call ノード処理で。ctxは state を必須にし、必要なら screen/root を mount に渡す。
const result = await parts[node.part].start({ state, mount: document.body }, node.args || {});
state = (result.effects || []).reduce((s, effect) => applyEffect(s, effect, flags), state);
state = advanceExecution(state, scene);
run();
```

シナリオ側の例:

```js
{ t:'call', part:'rebuttal', args:{ id:'day2_inquiry' } }
{ t:'call', part:'rebuttal', args:{ id:'day3_show' } }
{ t:'call', part:'jointReasoning', args:{ id:'wall_author' } }
{ t:'call', part:'jointReasoning', args:{ id:'wall_author', variant:'a4' } }
{ t:'call', part:'freeAction', args:{ day:1, blocks:4 } }
{ t:'call', part:'temariBoard', args:{} }
```

自由行動の本文表示・ブロック消化・終了復帰、各`call`のeffects反映、END遷移まで統合済みである。`other_scriptwriter_noticed`も正式フラグとして定義済みである。上のコードは現在の結線契約を示す参照用とする。

## 検証

`debug-parts.html`をローカルHTTPサーバーで開くと、各パートを独立起動できます。`node --test`で純粋関数、`node tools/シナリオ検証.mjs`でシナリオからの呼出し契約を検証します。
# 自由行動: 館の地図

自由行動の選択画面では、`src/data/mansion-map.js` を唯一の部屋定義として SVG 見取り図を描画する。部屋は `g[role="button"]` であり、通常の button にはしない。これは自動プレイが `.action-list [data-id]` の行動ボタンだけを押す契約を守るためである。

`revealedBy` を持つ部屋は対応するフラグ取得まで「？」として表示する。未割り当ての行動は地図上には置かず、一覧で「館のどこか」と表示する。
