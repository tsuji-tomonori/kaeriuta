# 『帰り唄 ―手毬唄の館―』音楽設計

親課題は #21。各曲の制作条件と物語上の役割は #22〜#37 に対応する。

## 音楽の立ち位置

本作はホラーではなく、家族史と作者名をめぐる文学ミステリーである。音楽は不安を煽り続ける装置ではなく、台詞と推理に集中できる余白をつくり、場面が変わったときだけ物語の温度を伝える。

- 物々しさは低い音量、遅い和声変化、木・弦・息の質感で表す。
- 恐怖を連想させる持続低音、半音衝突、金属的高音、心拍状の反復は常用しない。
- 2時間のプレイを前提に、通常曲は約2分、主旋律は8〜10小節ごととし、主題を鳴らさない区間を設ける。
- BGMだけで感情を決めつけず、環境音と無音も構成要素として扱う。

## 統一感と曲の違い

統一感は「同じ旋律」でも「同じ編曲テンプレート」でも作らない。控えめな音量と刺激の少ないアタックだけを共通の快適性として残し、旋律、拍節、和声変化、音域、残響、音の密度、楽器の役割は場面ごとに変える。

### 劇的コントラストの基準

| 状況 | 編曲文法 | 聴感上の目的 |
|---|---|---|
| 尋問 | 4小節ごとの単音、質問の後に遅い木管の返答、長い無音 | 相手の返答を待つ。常時緊迫させない |
| 通常推理 | 乾いたナイロンギターの三音セル、柔らかなマリンバ | 一人の頭の中で手掛かりがつながる明晰さ |
| A-4共同推理 | 左右に受け渡すピチカートと木管、後半だけ活動量を増す | 公開の場を二人で奪い返す機転と推進力 |
| 最終共同推理 | ギター、クラリネット、チェロの問答。進行に応じて弦が加わる | 役割分担で主張を崩す共同作業と到達感 |
| 逮捕 | 拍を置かず、狭い音域のピアノとチェロを沈黙で隔てる | 記録に閉じ込められる重さ。恐怖ではなく結果責任 |
| 脱出 | 6/4で歩くギター、高いフルート、広い定位と明るい高域 | 身体が外へ動く解放。未解決の余韻は残す |

通常推理から共同推理へ入る際は、システムが専用BGMへ明示的に切り替える。A-4と最終共同推理も同じ曲を使い回さない。

## 長時間再生の快適性

- 通常BGMは -25〜-27 LUFS-I、ENDは -24〜-25 LUFS-I、EDは -23.5 LUFS-Iを目標とする。
- 和声配置はプロファイルごとに変える。尋問は4小節ごとの単音、推理は小節単位の分散和音、逮捕は4小節単位の孤立音、脱出は小節ごとの歩行型とする。
- 主旋律は8〜10小節間隔を基本とするが、逮捕・口封じでは句を丸ごと休み、共同推理では問答として配置する。
- パルスは物語上の前進が必要な曲に限定し、尋問・逮捕・口封じでは使わない。クリックに聞こえる高音を使わない。
- 発音ごとにタイミング、強さ、長さ、位相、1〜2 centの音程差を決定的seedで変え、機械的な完全反復を避ける。
- マスターの減衰開始は5.5〜7.8 kHz、残響量は0.10〜0.68の範囲で場面別に変える。逮捕は乾いて近く、脱出は明るく広くする。台詞帯域へ細い定常ピークを作らない。

## 音色

外部サンプルに依存せず再生成できるよう、フェルトピアノは三本弦と弱いハンマーノイズ、弦と木管は発音ごとに異なる位相・息・弓成分、空気層は低次倍音だけで構成する。通常推理と脱出には短く減衰するナイロンギター、通常推理とA-4には高域を丸めた木製マレット、移動感には帯域を絞ったブラシを使う。純粋な正弦波の持続音、明るい三角波パッド、金属的ディレイは使用しない。

編集用MIDIはGMプログラムの目安を含む。LMMS、ArdourなどのDAWでSurge XTや適切なSoundFontへ差し替えられるが、リポジトリ内の決定的レンダーだけでも権利上安全に再生成できる。

## 技術契約

- BGMは48 kHz / stereo / Ogg Vorbis。ED以外はフェードの継ぎ目を作らないループ。
- true peakは -2 dBTP以下。環境音は -28 LUFS-I以下、SEは -21 LUFS-I前後を基準とする。
- `tools/audio/render.sh [track-id...]` でBGMを再生成し、`tools/音源生成.sh` で全BGM・環境音・SEを再生成する。
- `python3 tools/audio/check_audio.py` で形式、ラウドネス、ステレオ差、ループ境界、主題の固有性、旋律密度、劇的プロファイル、例示四場面の編成差を検査する。

## 編集可能な納品物

各曲の `assets/audio/source/<track-id>/` にStandard MIDIとcue sheetを置く。音色とイベントは `tools/audio/render_soundtrack.py` にあり、同一seedから再現できる。
