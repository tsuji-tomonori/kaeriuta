# 『帰り唄 ―手毬唄の館―』音楽設計

親課題は #21。各曲の制作条件と物語上の役割は #22〜#37 に対応する。

## 音楽の立ち位置

本作はホラーではなく、家族史と作者名をめぐる文学ミステリーである。音楽は不安を煽り続ける装置ではなく、台詞と推理に集中できる余白をつくり、場面が変わったときだけ物語の温度を伝える。

- 物々しさは低い音量、遅い和声変化、木・弦・息の質感で表す。
- 恐怖を連想させる持続低音、半音衝突、金属的高音、心拍状の反復は常用しない。
- 2時間のプレイを前提に、通常曲は約2分、主旋律は8〜10小節ごととし、主題を鳴らさない区間を設ける。
- BGMだけで感情を決めつけず、環境音と無音も構成要素として扱う。

## 統一感と曲の違い

統一感は「全曲が同じ旋律」で作らない。柔らかなピアノ、弦、木管、空気感、二小節単位の和声、控えめな音量を共通語彙とし、旋律と調性は場面ごとに変える。

## 長時間再生の快適性

- 通常BGMは -25〜-27 LUFS-I、ENDは -24〜-25 LUFS-I、EDは -23.5 LUFS-Iを目標とする。
- 和音は原則2小節ごと、低音アンカーは4小節ごとに鳴らす。常時鳴る低音ドローンを置かない。
- 主旋律は8〜10小節間隔とし、密度の低い曲では一つの句を丸ごと休む。
- パルスは12小節中4小節以下の活動窓だけで鳴らし、クリックに聞こえる高音を使わない。
- 発音ごとにタイミング、強さ、長さ、位相、1〜2 centの音程差を決定的seedで変え、機械的な完全反復を避ける。
- マスターは6.8 kHzから穏やかに減衰させ、残響は4.2 kHz以下へ暗くする。台詞帯域へ細い定常ピークを作らない。

## 音色

外部サンプルに依存せず再生成できるよう、フェルトピアノは三本弦と弱いハンマーノイズ、弦と木管は発音ごとに異なる位相・息・弓成分、空気層は低次倍音だけで構成する。純粋な正弦波の持続音、明るい三角波パッド、金属的ディレイは使用しない。

編集用MIDIはGMプログラムの目安を含む。LMMS、ArdourなどのDAWでSurge XTや適切なSoundFontへ差し替えられるが、リポジトリ内の決定的レンダーだけでも権利上安全に再生成できる。

## 技術契約

- BGMは48 kHz / stereo / Ogg Vorbis。ED以外はフェードの継ぎ目を作らないループ。
- true peakは -2 dBTP以下。環境音は -28 LUFS-I以下、SEは -21 LUFS-I前後を基準とする。
- `tools/audio/render.sh [track-id...]` でBGMを再生成し、`tools/音源生成.sh` で全BGM・環境音・SEを再生成する。
- `python3 tools/audio/check_audio.py` で形式、ラウドネス、ステレオ差、ループ境界、主題の固有性、旋律密度を検査する。

## 編集可能な納品物

各曲の `assets/audio/source/<track-id>/` にStandard MIDIとcue sheetを置く。音色とイベントは `tools/audio/render_soundtrack.py` にあり、同一seedから再現できる。
