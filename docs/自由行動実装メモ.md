# 自由行動実装メモ

## 変更ファイル

`src/systems/freeaction/index.js`、`src/styles/追加-freeaction.css`、`tools/ブラウザ検証/進行基盤.js`、`test/freeaction-risk.test.js`、本書。シナリオ本文は保持し、自由行動データの補完は freeaction 側の `actionDetails` に集約している。他の担当外ファイルは編集していない。

自由行動は、主要な手掛かりを選択直後に確定し、続く「どこを見る？」では付随する記録と一部の知りすぎだけを分岐させる。従って、選ばなかった注目箇所によって章の到達条件が欠けることはない。

見返りと代償は常に行動一覧と部屋詳細へ表示する。見返りだけは既存の自由探索ヒント設定に従って補助表示を隠せるが、代償は設定に関係なく表示する。札の表示は items の power / exposure を任意で参照し、並行編集で未定義でも画面を止めない。

| 行動 | 見返り | 代償 | 分割・注目箇所 |
| --- | --- | --- | --- |
| 書斎 | 献辞 | 疑い+10 | 献辞／綴じ（知りすぎ） |
| 家政婦 | 地下の音 | 良心+1 | 指先／地下（知りすぎ） |
| 共犯者の部屋 | 別の計画書 | 信頼-1 | 時刻／注記（知りすぎ） |
| 準備 | 配膳・読書記録 | 疑い+4 | 当番／読書記録 |
| 探偵観察 | 質問の順序 | 警戒+1 | 悟郎／コウ君（知りすぎ） |
| 館探索 | 空白と旧道 | 疑い+5 | 壁／旧道（知りすぎ） |
| 安置室 | 筆だこ | 知りすぎ+1 | 手／インク（追加で知りすぎ） |
| 主治医 | 控えカルテ | 疑い+5 | 複写紙／言いよどみ（知りすぎ） |
| 厨房 | 当番と献立 | 良心+1 | 当番／茶葉 |
| 書斎再訪 | 初版本の余白 | 疑い+6 | 余白／最終章（知りすぎ） |
| 旧道 | 三里先の道 | 疑い+3 | 唄／地図 |

新設した通常の代償は、家政婦: conscience +1、共犯者の部屋: trust -1、探偵観察: awareness +1、館探索: suspicion +5、安置室: overknow +1、厨房: conscience +1。深く読む選択は章ごとに複数あり、追加の overknow +1 を伴う。

## 実ブラウザでの確認手順

第一章で「書斎を調べる」を選び、献辞または綴じを押す。選択一覧と書斎詳細に見返り・代償があり、注目画面では `#next` なしで二つの注目ボタンだけが出ることを確認する。続く画面で手掛かりの内容を確認し、「次の行動を選ぶ」で一覧へ戻る。第二章の死体安置室では、基本の知りすぎと深く読む選択の追加分が働くことも確認する。

## 未実装・判断

既存の長い `narrative` は削除せず保存した。表示には段落から抽出した intro / 発見 / reaction を用い、主要報酬は注目前に確定する。items の power / exposure はトラックBの並行編集に追随するため、未定義時は表示を省略する。

## actFreeAction 差分

変更前:

```js
function actFreeAction(modal) {
  if (modal.querySelector('.freeaction-narrative #next')) return click(modal.querySelector('.freeaction-narrative #next'), 'freeaction:read-next');
  const actions = [...modal.querySelectorAll('.action-list [data-id]')];
  const action = options.choosePart ? actions[options.choosePart('freeAction', actions)] || actions[0] : actions[0];
  if (action) return click(action, `freeaction:action:${action.textContent.trim()}`);
  return click(modal.querySelector('#done'), 'freeaction:confirm');
}
```

変更後:

```js
function actFreeAction(modal) {
  const focuses = [...modal.querySelectorAll('.freeaction-narrative [data-focus]')];
  if (focuses.length) {
    const focus = options.choosePart ? focuses[options.choosePart('freeAction', focuses)] || focuses[0] : focuses[0];
    return click(focus, `freeaction:focus:${focus.textContent.trim()}`);
  }
  if (modal.querySelector('.freeaction-narrative #next')) return click(modal.querySelector('.freeaction-narrative #next'), 'freeaction:read-next');
  const actions = [...modal.querySelectorAll('.action-list [data-id]')];
  const action = options.choosePart ? actions[options.choosePart('freeAction', actions)] || actions[0] : actions[0];
  if (action) return click(action, `freeaction:action:${action.textContent.trim()}`);
  return click(modal.querySelector('#done'), 'freeaction:confirm');
}
```
