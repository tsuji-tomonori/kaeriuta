# 仕上げ波: 章末サマリを変化の記録にする

## 判断

G-4 は **(a)** を選んだ。第三章は札を増やす章ではなく、栞が「実行」か「告白」かを選び、その選択が第四章の反論／共同推理の入口を決める章である。そこで空の札帳簿を出す代わりに、選んだ頁、信頼・良心の変化、第四章で開いた道を表示する。

`gazeValue` の正本は `src/systems/rebuttal/index.js` の named export に置き、END解説はそこから import する。尋問画面とEND画面で同じ式を使う。
