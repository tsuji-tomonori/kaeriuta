# 『帰り唄 ―手毬唄の館―』物語・演出評価

## 1. 総評

面白い。いちばん強いのは、倒叙の主人公を「悪事を隠す人」だけでなく、事実を知ったまま“初見の反応”を演じなければならない司書にしたことだ。コウナンの登場から、栞は手掛かりを集めるほど無垢な観察者ではいられなくなる。この仕掛けが、一般的な館ミステリの探索を「情報を得る快感」と「得たことを悟られる怖さ」の両方に変えている。特にA-1は、謎を解けなかった罰ではなく、知っていて黙った栞が逮捕される結末になっており、倒叙として芯が通っている。

一方で、緊張の山を作ったあとにテーマの独白で同じ結論を何度も確認する癖がある。第四章Bは隠し部屋発見、律の署名、宗玄との対決、共同推理という十分に強い四段のあと、最終選択までに「憎しみを物語にしない」「律を読者へ返す」を長く反復する。文章単位では良いが、プレイヤーが選ぶべき瞬間の手前で自分の選択理由をすでに説明され切るため、B-1の到達感を少し削っている。削るなら隠し部屋の生活描写ではなく、共同推理後の内省を三分の一程度に圧縮し、宗玄の挑発を早く差し込むべきである。

人物は栞とコウナンが明確に立つ。栞の図書館語彙は比喩の飾りではなく、観察・隠蔽・責任の理解方法になっている。コウナンも単なる正義の探偵でなく、「見張る」ことで栞を守りもする相手として機能する。ただし鬼灯家の脇役は、剛蔵＝虚勢、藤乃＝震え、真壁＝整理する編集者、佐伯＝言い淀む医師という最初の記号が有効な反面、終盤で各人が自分の選択を決定的に語る場面が薄い。宗玄と律の対立が太いぶん、交換殺人に参加した家族が「大きな脚本に使われた者」へ均される。

七ENDは色分けではなく、A系を「罪を引き受ける／逃げる／利用されたと知る／自白して告発する」、B系を「真相を返す／断罪に閉じる／口を塞がれる」に分けられている。なかでもA-4は犯人ルートのまま主導権を奪い返すため、B-1とは別種の高揚がある。反対にB-2は宗玄が死を仕掛けへ変える因果の見せ場が省かれ、思想的には正しい未完でも、劇としてはB-1の陰画に寄り過ぎる。宗玄の死の具体的な選択を一場面だけ置けば、栞が「許さない」を選んだ結果の苦さが自分の物語になる。

## 2. 効いている点

- **司書の職能が倒叙の緊張に直結している。** コウナンを危険だと判断した直後の「返却期限を過ぎた本に腹を立てても、司書はまず受取日を記録する。」は、栞の平静が美徳でなく偽装の手順であることを一文で示す。以後の「記録」「照合」「返却」は、罪の隠蔽から責任の引受けへ意味を変える。出典：`mikiri.md` step 69。

- **コウナンは栞の倫理を照らす対抗者になっている。** A-1で「知っていたことまで、罪にしないで。……でも、知ってるのに誰かをひとりにしたことは、忘れちゃだめだよ。」と言うため、逮捕を単なる敗北にせず、栞の不作為を読者へ残す。犯人を追い込む役が道徳的な勝利宣言をしないのがよい。出典：`endings.js` / `end_a1`。

- **律を“美しい被害者”にしない回収が、題材を一段深くしている。** 「あなたはいつも、苦しみまで見栄えよく書き直す。けれど律さんは、きれいな被害者じゃない。腹を立てて、眠れなくて、書き損じて、それでも生きた人よ。」は、隠し部屋の茶渋・寝具・書き損じを、悲惨さの装飾で終わらせず作者性の証拠に変える。出典：`suiri.md` step 717。

- **手毬唄の用途がENDごとに変化する。** A-2では「五番の唄の三里先へ、私は旧道を下った。」と脱出路になり、B-1では「閉じるのは幕ではない。本だ。」と題名の再解釈になる。同じ歌がトリックの飾り、空間の地図、倫理的な結末の順に機能を変えるので、六番まで読ませる長さに意味がある。出典：`toubou.md` step 799、`suiri.md` step 763。

- **A-4は“犯人側であること”を捨てずに反転する。** 「自白は、免罪のための鍵ではなかった。」から始めて栞自身の罪も卓上へ載せるため、成功ENDを無罪放免にしない。B-1の救済と異なる、責任を負った告発の読後感がある。出典：`endings.js` / `end_a4`。

## 3. 改善点

### 優先度：高 — Bルート終盤の内省を圧縮し、最終選択へ余白を返す

1. **現状の問題**：共同推理直後から六番選択まで、栞が「宗玄に悲劇の主役を与えない」「律を読者へ返す」という同一の判断を連続して説明する。プレイヤーが選択で結論を出す前に、B-1の正答の倫理がほぼ確定する。
2. **根拠**：「崩したのは、彼の言葉の壁だった。けれど壁の向こうで四十年を過ごした人の時間まで、証拠カード一枚で返せるわけではない。」（`suiri.md` step 736）の後、同趣旨の内省がstep 738、740、742、744、746、748、750、752、753と続き、宗玄の「誰にも変えられん。」はstep 754に来る。引用したstep 736自体は必要だが、対立者の反撃が遅い。
3. **具体的な改善案**：step 736相当の一段を残し、折句の主体性を述べる一段と、六番を「閉じる」ではなく「返す」と読む一段だけに統合する。宗玄の挑発を共同推理直後へ前倒しし、残す二段を挑発への応答として置く。
4. **想定される副作用**：律の救済テーマを読み落とすプレイヤーが出る。対策として削除した情報の一部を、最終選択肢のヒントか手帳の原稿カードに移す。

### 優先度：高 — B-2の宗玄の死を演技として成立させる

1. **現状の問題**：B-2は宗玄が“死を仕掛けにした”結果だけを語り、直前に何を選び、誰が止められず、どう証拠が崩れたのかを見せない。断罪を選んだ栞の能動性が、場面外の出来事に回収される。
2. **根拠**：「宗玄は自らの死を、また一つの仕掛けに変えた。」（`danzai.md` step 771）の直後に「県警が到着したとき、残った証拠は互いに矛盾していた。」（step 773）へ飛ぶ。自死・逃走・偽装のいずれかを画面内で特定できない。
3. **具体的な改善案**：時計、壁、宇野、原稿のうち一つを使い、宗玄が自分で証拠連鎖を断つ短い演出を追加する。栞が止めようとして一歩遅れる描写を置き、「許さない」が宗玄の望む悲劇を完成させた、という因果を行為で見せる。
4. **想定される副作用**：B-2が宗玄の見せ場に寄り過ぎる恐れがある。栞の視点を固定し、彼の行為を完全には見せず、栞が選ばなかった言葉への後悔を中心に置く。

### 優先度：中 — 鬼灯家・共犯者に終盤の固有の決断を与える

1. **現状の問題**：剛蔵、藤乃、真壁は導入の造形が鮮やかな一方、物語の終盤では栞と宗玄の対立を見守る配置になりやすい。交換殺人の共犯者であることの個別の痛みが、栞の罪へ吸収される。
2. **根拠**：剛蔵の「……食えよ、みんな。毒見なら俺がしてやる。ほら、こうして食って見せりゃいいんだろ。」は虚勢と恐怖を同時に立てている（`mikiri.md` step 433）。しかしA-1では「剛蔵兄さんは何か言いかけ、結局グラスの縁を握った。藤乃姉さんは唇を震わせたまま、私の名を呼ばなかった。」に留まる（`endings.js` / `end_a1`）。
3. **具体的な改善案**：各人に一行ずつ、栞の処遇または宗玄の告発に対して自分の利益を損ねる選択をさせる。例として剛蔵は計画書を出す、藤乃はトヨの記憶を証言する、真壁は自分の編集上の加担を認める。全ENDへ同量に配る必要はなく、A-4/B-1だけでもよい。
4. **想定される副作用**：終盤のテンポが鈍り、栞の主役性が薄くなる。台詞は一人一行までにし、栞の選択の後にだけ発火させる。

### 優先度：中 — 隠し部屋の発見を「物」から「選択」へ一段つなぐ

1. **現状の問題**：隠し部屋の物品描写は優れているが、書き損じ、正の字、寝具、鉛筆、手紙、日付が連続し、コウナンと栞がその場で何を異なって読むかが薄い。発見の衝撃が鑑賞に寄り、次の共同推理への推進力が一度落ちる。
2. **根拠**：「『二章の動機が弱い』『この人物は帰れない』『結末は、読者を置いていくな』。」（`chapter4b.js` / `chapter4b`、隠し部屋・原稿メモ場面）は律を作者として立ち上げる強い素材だが、その後も生活痕の独白が続く。ログ上、同発見区間は `suiri.md` step 690台後半から717の対決開始までである。
3. **具体的な改善案**：生活痕は「書き損じ＋茶渋＋日付」の三点に絞り、コウナンが筆跡・栞が読書メモをそれぞれ読む短いやり取りを挟む。削った寝具や手紙は手帳の任意閲覧へ回す。
4. **想定される副作用**：律の四十年の物量が減る。任意資料に残すことで、深く読みたいプレイヤーの受け皿は維持できる。

### 優先度：低 — 司書比喩の密度を場面ごとに一度へ整える

1. **現状の問題**：栞の語彙は作品の武器だが、高圧の場面でも「頁」「本」「栞」「返却」が近接して続くと、感情の運動よりレトリックの認識が先に立つことがある。
2. **根拠**：A-2だけでも「返却口のない本を抱えて、別の棚へ移ることだ。」（`toubou.md` step 805）、「本の背表紙を見れば」（step 809）、「背表紙の裏に残った」（step 811）と連続する。各文は正確だが、逃走の肉体感を薄める。
3. **具体的な改善案**：各場面で最も強い一つだけを残し、他は泥・息・手錠・水など現在の身体感覚に置換する。比喩を減らすのでなく、決め台詞へ集中させる。
4. **想定される副作用**：栞の文体が平板になる危険がある。改稿は全体一律にせず、追跡・対決など速度が必要な場面だけに限定する。
