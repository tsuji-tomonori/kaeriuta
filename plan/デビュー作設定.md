# デビュー作設定(改稿版)―『手毬唄殺し』二段底の結末

**設計方針の変更点**:「二番の死者=生きている演出家」はデビュー作の**表のトリックにはしない**。
刊行版の結末は別の犯人で閉じられており、注意深い読者だけが本文中の"宙に浮いた手がかり"から**もう一つの解**――二番の死者が生きていた――を再構成できる。
そして「なぜ真の解が葬られたのか」を追うと、ゴーストライターの存在が浮かび上がる。

## あらすじ(刊行版)

> 深い山峡の旧家・六唄(むうた)家。当主の隠居祝いに縁者が招かれ、豪雨で吊り橋が落ち、屋敷は陸の孤島となる。その夜から、土地の手毬唄「六つの唄」になぞらえて客が死んでいく。一番の唄で盃の客が眠り、二番の唄で「のっぺらぼうの仏」――当主の顔なし死体――が座敷に座る。
>
> 【刊行版の結末】旅の学士が指名した犯人は、**分家の青年**。遺産と積年の恨みによる犯行とされ、物語は閉じる。
>
> ――だが、この結末では**いくつもの伏線が回収されない**。読者の間では40年来、「あの結末は本当に作者の書きたかったものか」という論争が続いている。

## 二段底の構造

### 表の解(刊行版)
犯人=分家の青年。筋は通るが、凡庸。前半の精緻さと釣り合わない。

### 裏の解(葬られた真相)
**二番の唄で死んだはずの当主が生きており、屋敷の壁の内から一切を演出していた。**

刊行版の本文に残る"宙に浮いた手がかり"は、すべてこの解でのみ意味を持つ:

| 未回収の伏線(刊行版本文に現存) | 裏の解での意味 |
|---|---|
| 事件後も米の減りが一人分多い、と女中が呟く場面 | 隠れた当主の食事 |
| 仏間の線香が誰も上げないのに増えている | 当主が夜ごと自分の"仏前"に参っている |
| 顔なし死体の手が「働き者の手」だと学士が一度だけ指摘し、以後触れない | 遊んで暮らした当主の手ではない=死体は別人 |
| 蔵の錠に**内側からの**引っ掻き傷 | 壁内に人が出入りしていた |
| 手毬唄五番だけ、屋敷の子が「誰に習ったか覚えていない」 | 壁の内から聞こえた唄を覚えた |

> **重要**:伏線は物語全体に織り込まれているため、宗玄には除去できなかった。彼が差し替えたのは**最終章だけ**。錠は掛け替えられたが、鍵は敷石の下に残されたままの家――それが刊行版『手毬唄殺し』である。

### なぜ最終章は差し替えられたのか
律の原稿『帰り唄』の最終章は、**「死んだことにされた男が、生きたまま屋敷の内に隠されている」**ことを暴く内容だった。監禁2年目の宗玄にとって、それは自分の犯行の記述そのものであり、告発であり、予言だった。世に出せるはずがない。宗玄は最終章のみを自分の筆で書き直し、無難な犯人を接ぎ木して刊行した。

そして律の側から見れば、この最終章は**構造の水準で仕込まれた救難信号**だった。「いつか誰かがこの本を本当に読み解けば、壁の内の男に辿り着く」――折句が「文字」の水準の署名なら、裏の解は「物語」の水準のSOS。唄が**誰**を告げ、結末が**どこ**を告げる。

## 現在の事件との接続 ―「宗玄は、葬った結末を上演している」

宗玄の"遺作"は、刊行版ではなく**自らが削除した真の結末**の再演である。二番の唄で死を偽装し、壁の内から演出する――40年間封印してきた「盗んだ物語の本当の終わり方」を、最後に自分の作品として演じようとしている。

したがって本作の推理構造はこうなる:

> **現在の事件を予測できるのは、「葬られた最終章」を読んだ者、あるいは刊行版の未回収伏線から裏の解を再構成できた者だけ。**

事件を解く鍵が「削除された章を読むこと」自体である――ゲーム全体の推理目標と、盗作の暴露が一本の線で重なる。

## 発覚までの証拠チェーン(改稿版)

### 仕掛け0【背骨】:葬られた最終章
1. **未回収伏線の認知**:刊行版を読む/ファンの間の「当主生存説」論争を知る(書斎の同人誌・恩田の書き込み本)
2. **裏の解の再構成**:伏線を突き合わせ「二番の死者は生きていた」に到達 → **現在の事件の型と一致**することに戦慄(👁への最短経路)
3. **生原稿『帰り唄』最終章の発見**(地下のトランク/🕯最重要アイテム):裏の解がまさに書かれている → 「差し替えたのは誰か、なぜか」
4. **文体照合**:刊行版の最終章"だけ"が、宗玄唯一の真筆長編『冬の灯』(仕掛け5)と同じ癖を持つ → **最終章を書いた男と、それ以外を書いた男は別人**。文体の三角測量で決着

### 仕掛け1:折句(き・り・は・ら・り・つ=霧原律)
変更なし。栞専用の「最後の一枚」。裏の解が**どこ**を示し、折句が**誰**を示す、という役割分担を明確化。

### 仕掛け2:存在しない民謡(初出の欠落)
恩田の役割を強化。**デビュー時の担当編集だった恩田は、入稿直前に最終章が差し替えられたことを唯一知る男**。近年、唄の初出が存在しないことに気づき、二つを結んで強請りに至った(=一番で殺された理由が「裏の解」に直結する)。恩田の部屋の書き込み本(欄外注釈)が、プレイヤー/コナン双方への導線になる。

### 仕掛け3:筆跡と利き手(左で書かれた物語)
変更なし。生原稿の左利きの筆致 vs 受賞式写真の右手。

### 仕掛け4:見えすぎる館(内側からの視点)
変更なし。出格子の笹の影の描写=牢の内側の視点。裏の解の「壁内の男」と実地の隠し構造が照合される合流点。

### 仕掛け5:一冊だけの駄作(文体の指紋)
仕掛け0-4と接続強化。『冬の灯』は「宗玄の文体標本」として機能し、刊行版最終章の正体を暴く物差しになる。

## コナンの読書進行(ゲームシステムとしての作中作)

| 段階 | コナンの状態 | プレイヤーの介入 |
|---|---|---|
| 1 | 宗玄の蔵書から『手毬唄殺し』を手に取る | 先に本を隠す/貸す(隠すと進行遅延、ただし「本が消えた」こと自体を怪しまれるリスク) |
| 2 | 読了。「……変な小説。前半と最終章で、伏線の張り方が別人みたいだ」 | 「有名な論争ですよ」と教える(進行加速)/「気のせいでは」と流す |
| 3 | 未回収伏線から裏の解を再構成。「もし当主が生きてたなら全部つながる。……この館の事件と、同じように」 | ここまで進むと👁系の捜査が一気に加速。実行ルートでは最大の脅威、告白ルートでは最強の追い風 |
| 4 | 恩田の書き込み本 or 生原稿を入手すると、盗作の可能性まで到達(ただし折句には届かない) | 生原稿を先に確保して渡す/燃やす、の選択も可能(燃やすと真相ENDが閉じる不可逆選択) |

## デザインノート

- 二段底にしたことで、デビュー作は「読めば答えが書いてある本」から**「正しく読んだ者にだけ答えが開く本」**になった。コナン・栞・プレイヤーの三者それぞれに"読解"の段階を与えられ、読書進行そのものがゲージとして機能する
- 「凡庸な最終章」という世評は、宗玄の作家人生への静かな皮肉として全編に響く。彼が世界に恨まれた唯一の批判は、彼が唯一自分で書いた部分に向けられていた
- 5系統の仕掛けは引き続き「音(折句)・不在(初出)・手(筆跡)・眼(視点)・声(文体)」の器官対応。仕掛け0はそれらを束ねる**背骨**であり、単体では「改稿の事実」までしか示さない=折句の価値を食わないバランスを維持
