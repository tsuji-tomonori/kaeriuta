## 情報フラグ(3系統)

終盤の反論・推理の成否は演出ではなく、フラグ所持数で機械的に決まる。

- 🕯 **【過去】** … 40年前と霧原律の存在(献辞の消し跡/筆跡の異なる生原稿/律の万年筆/地下のダムウェーター 等)
- 📜 **【計画】** … 共犯計画の矛盾(他者の計画書/指示メモの筆跡/標的リストの法則 等)
- 👁 **【生存】** … 宗玄生存の証拠(死体のペンだこ/隠し通路の埃/消える食事/覗き穴 等)

## プロローグ(0日目 夜)「招かれざる客」

**目的**:世界観・人物・システムの導入。次女の動機の提示。

### 主要イベント
1. 別荘到着。招待客の顔見せ(共犯者5名+コナン一行+使用人)
2. 還暦の宴。宗玄の挨拶「今夜から、私の最高傑作が始まる」(二重の意味)
3. 次女、赤い蝶ネクタイの少年を視認。**血の気が引くモノローグ**
4. 深夜、橋の崩落と通信断絶を確認(共犯者視点では「予定通り」)
5. 暖炉に最初の指示メモ。チュートリアル:疑惑ゲージ/行動ブロックの説明

### 選択肢(例)
- 宴での座席選び(コナンの近く/遠く)→ 以後の観察イベントの起点
- 乾杯の口上を「聞き流す/注視する」→ 注視で🕯の種(宗玄の指に筆だこがない違和感)

## 第一章(1日目)「一番の唄」

**目的**:仕込みの日。「探偵の眼前で犯罪を準備する」緊張の確立。

### 固定イベント
- **朝**:第一の死体発見(元編集者・毒殺)。手毬唄一番との一致にコナンが気づく
- **昼**:小五郎が探偵として仕切り始め、簡易聴取(疑惑ゲージ初稼働)
- **夜**:共犯者の一人と秘密接触。「計画書の食い違い」に気づける最初の窓

### 自由行動(朝昼夕夜のうち3ブロック)
| 行動 | 主な報酬 | リスク |
|---|---|---|
| 書斎を調べる | 🕯 献辞の消し跡・初版本の謎 | コナンと鉢合わせ(疑惑↑) |
| 家政婦と話す | 🕯「昔、地下で物音が」証言 | ― |
| 共犯者Aの部屋へ | 📜 計画書の差異 | 発見されると共犯者間の不信 |
| 犯行準備 | 実行ルートの成功率↑ | 情報フラグを逃す |
| コナン一行の観察 | 疑惑の現在値を推定できる | 観察を観察される |
| 館の探索 | 👁 寸法の不一致/脱出路候補 | ― |

### 章末
夜、遠くでかすかなタイプライターの音(🕯)。次女のモノローグ「明日の夜――私の番が来る」。

## 第二章(2日目 朝〜夕)「二番の唄」

**目的**:世界の崩壊。主催者の"死"で計画への信頼が壊れ、疑念が主犯探しへ向かう。

### 固定イベント
1. **朝**:大広間で**宗玄の顔なし死体**発見(実体は霧原律)。座は恐慌へ
2. **死体発見時の選択**:「手元を見る/顔の傷を見る/黙って下がる」
   - 手元→👁(ペンだこ)。ただし凝視しすぎるとコナンに観察され疑惑↑
3. **昼**:小五郎の本格尋問=**反論パート①(小規模)**
   - 論理チェーン3ノード程度。「反証/沈黙/転嫁」の操作を教えるチュートリアル戦
   - ここでの立ち回りが3日目の推理ショーの初期疑惑値を決める
4. **夕**:共犯者たちの動揺。「計画者は死んだ。続けるのか?」の密談
   - 📜が一定数あると「指示メモの筆跡が宗玄の直筆と一致しない=口述筆記のはずでは?」に気づける

### 自由行動(2ブロック)
1日目と同系統+新規:「死体安置室に忍び込む(👁)」「主治医を探る(📜 歯型カルテの改ざん)」

## 第三章(2日目 夜)「岐路」――最大の分岐

**目的**:物語の背骨。プレイヤーに人生の選択を強制する。

### 演出
決行時刻が迫る。暖炉に「今夜、予定通りに」のメモ。同時に、廊下でコナンから「夕食のあと、少しいいですか」。柱時計が鳴り、画面が二つに割れる――

> ### 🔪 凶器を取る  /  🚪 少年の部屋の扉を叩く

**スキップ不可・保留不可。必ずどちらかを選ぶ。**

- 選択前に「これまでに集めたフラグ一覧」が走馬灯として流れる(情報量の自覚を促し、選択に重みを与える)
- どちらを選んでも「正解」ではないことをUIで示唆(達成率表示などは出さない)

## 第四章A(3日目)「償いの唄」――実行ルート

**目的**:証拠隠滅と防衛戦。倒叙ミステリーの本懐。

### 流れ
1. **2日目深夜**:犯行実行(描写は簡潔に、選択の重さを演出)。直後、現場で「予定と違う何か」を目撃できる(👁/📜の最終獲得チャンス)
2. **3日目朝**:第三の死体(三番の唄)も同時発見――自分以外の誰かも動いていた事実に戦慄
3. **午前**:**眠りの小五郎・推理ショー=反論パート②(本戦)**
   - 論理チェーン6〜8ノード。「反証/沈黙/転嫁」を取捨選択
   - 反証には1〜2日目に仕込んだ偽証拠・偽アリバイのみ使用可(準備不足はここで詰む)
   - 「知りすぎ判定」:犯人しか知らない情報での反証は、論破成功でも疑惑急騰
4. **正午**:トラック発見の一報。カウントダウン開始

### エンド分岐
| END | 条件 |
|---|---|
| **A-1 逮捕** | 反論失敗 or 疑惑閾値超過。名指しの後、コナンの静かな一言で幕 |
| **A-2 脱出** | 反論成功+事前に脱出路確保(五番の唄「三里先」の旧道 等)。ラストにコナンの視線 |
| **A-3 操り人形** | 📜👁不足のまま実行。自分の犯行が「四番の脚本」だったと突きつけられる |
| **A-4 逆転(隠し)** | 👁+📜+🕯を高水準で所持。推理ショーの最中に挙手し、**推理を乗っ取って隠し部屋の宗玄を暴く**。共同推理パートの変則版へ接続 |

## 第四章B(3日目)「五番の夜」――告白ルート

**目的**:視線の反転。「疑惑の管理」から「殺意の管理」へ。

### B-1節:告白(2日目夜〜)
- **接触方法の選択**(宗玄の"察知"パラメータに直結/覗き穴と内通者に監視されている):
  - コナンの部屋を直接訪ねる(察知・大)
  - 蘭を介して自然に近づく(察知・中)
  - 本に挟むメモで呼び出す(察知・小/📜で連絡手段を知っている場合のみ解禁)
- コナンは即信しない。「罠の可能性」を疑う。**物証(計画書・指示メモ等)の提示数**で信頼度が決まり、不足だと「泳がされる」高難度展開に

### B-2節:標的化の回避(3日目 未明まで)
- 告白の素振りが宗玄に察知されると、次女は**五番の唄「逃げた小鳥」として処刑リスト入り**
- 振る舞いの選択:「共犯者のフリを続け偽の犯行準備を演じる/部屋に籠る/コナンの側を離れない」
  - 籠城は一見安全だが「行動が変わった」こと自体が察知↑
- **五番の夜イベント**(察知が閾値超過時):暗殺者が来る。
  - 囮の仕込み(事前選択)/コナンとの合図(信頼度)/隠し通路の知識(👁)の有無で
  - → 回避成功/コナンに救出/**B-3 口封じEND** に分岐

### B-3節:共同推理(3日目 午前)
- 隠し部屋を特定し、宗玄と対峙。**コナンとの二人推理ショー**
- 宗玄の主張ノード(「私は死んでいた」「あの死体は私だ」「唄は私が書いた」…)を、
  「自分が暴く/コナンに任せる/律の遺品を突きつける」で一枚ずつ崩す
- **最後の一枚「唄の真の作者」はコナンも知らない**。🕯を深部まで集めた次女にしか砕けない
- 提示順は自由。外堀から埋めるか核心から突くかで宗玄の反応(表情差分)が変化

### B-4節:六番の阻止(最終局面)
- すべて暴かれた宗玄は、脚本の最終行――自らの手で物語を閉じること――だけは譲らないと告げる
- 派手なギミックではなく、**40年分の真実からどの言葉を選んで投げるかの選択**
- 🕯最深部(唄の最終節の本当の意味/折句)を持っているか否かが結末を分ける

### エンド分岐
| END | 条件 |
|---|---|
| **B-1 真相(トゥルー)** | 標的化回避+共同推理完遂+六番の阻止成功 |
| **B-2 未完** | 真相は暴くが、六番を止められない。事件は「死者が主犯」として閉じられる |
| **B-3 口封じ** | 察知超過+防衛失敗(コナン救出の小分岐あり) |
