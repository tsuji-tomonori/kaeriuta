# 反論パート① プロトタイプ ―「二日目昼の尋問」

第二章・昼の固定イベント。宗玄の"死体"発見後、大広間で小五郎が招待客を順に聴取する。
本パートは**チュートリアル戦**:ノード操作(反証/沈黙/転嫁)と「知りすぎ判定」「証言ログ」を体験させる。

---

## 状況設定

- 議題は**一番の殺人(元編集者・恩田の毒殺)**。宗玄の死で場が荒れる中、小五郎は「まず最初の事件から整理する」と宣言
- 恩田は0日目深夜、自室で夜食の珈琲とともに死亡していた
- 実行犯は長男・剛蔵。だが状況証拠は**栞(プレイヤー)に向いている**――0日目夜、栞が厨房にいたのを蘭が目撃しているため
- 栞は無実(この件では)。しかし**共犯者として計画の全容を知っている**――ここが罠になる

---

## UI構成(画面イメージ)

```
┌─────────────────────────────────────────────┐
│  小五郎の確信度  ▓▓▓▓▓░░░░░  52%            │ ← 時間経過と失策で上昇
│  疑惑ゲージ      ▓▓▓░░░░░░░  (非表示・内部値) │
├─────────────────────────────────────────────┤
│   [前提]──────[論理]──────[物証]             │ ← 論理チェーン
│    N1  ──────  N2  ──────  N3               │    点灯中ノードに応答する
│                                             │
│   👓 ← コナンの視線アイコン(注視中は点滅)     │
├─────────────────────────────────────────────┤
│  ▼ 応答を選択                                │
│   [反証する]  [沈黙する]  [転嫁する]          │
│   └ 反証選択時:手札(証拠カード)から1枚提示   │
└─────────────────────────────────────────────┘
```

- **反証**:証拠カードをノードに提示。正解なら鎖が砕けるSE+確信度低下
- **沈黙**:耐える。ノードは残るが、リスクなし(ただし全ノード沈黙だと確信度が押し切る)
- **転嫁**:「それなら、あの人にも…」と矛先を他者へ。成功率は📜フラグ依存。無実の者に着せると隠しパラメータ「良心」低下(告白ルートの結末に影響)

---

## 本編スクリプト

### 導入

> 小五郎「まず恩田さんの件だ。毒は夜食に混入された。……栞さん、あんた、あの晩厨房にいたそうだな?」
> (蘭、申し訳なさそうに目を伏せる)

### ノードチェーン展開

```
[N1 前提]              [N2 論理]                [N3 物証]
毒は夜食の珈琲に   →   珈琲を淹れて運べたのは → カップに残った
混入された             厨房にいた栞さんだけ      あんたの指紋
```

---

### ◆ N1「毒は夜食の珈琲に混入された」

| 選択 | 手札/内容 | 結果 |
|---|---|---|
| 反証A | カード【厨房の献立表】 | ✕ 無関係。「何が言いたいんだ?」確信度+5 |
| 反証B | (口頭)「毒は珈琲ではなく、寝酒の方では?」 | **☠ 知りすぎ判定**。計画書で知る情報。コナンの視線が点滅→「…お姉さん、なんでそう思うの?」疑惑+15 |
| **沈黙 ◎** | ― | ○ 正解。事実なので争わない。「否定しないんだな」で次へ |
| 転嫁 | 「珈琲なら誰でも触れたはず」 | △ 部分成功。確信度-5だが、N2で切り返される |

> **設計意図**:最初のノードで「正しい知識を使うと死ぬ」ことを教える。倒叙の基本文法=**知らないフリの管理**をここで学習させる。

---

### ◆ N2「珈琲を淹れて運べたのは、厨房にいた栞さんだけ」

| 選択 | 手札/内容 | 結果 |
|---|---|---|
| **反証A ◎** | カード【配膳の当番メモ】(1日目昼「厨房を手伝う」で入手) | ○ 正解。「恩田さんへの夜食は家政婦さんが運んだ。私は自分の白湯を取りに行っただけ」→鎖破壊、確信度-15 |
| 反証B | カード【自室の読書記録】 | ✕ 裏付けが弱い。「本なんて何時でも読める」確信度+5 |
| 沈黙 | ― | △ 確信度+10。追い詰められモノローグ |
| 転嫁A | (📜所持時のみ解禁)「珈琲のポットに後から近づいた人がいます――剛蔵兄さんが」 | ○ 事実であり成功。確信度-20。**ただし共犯者を売った事実が残り、剛蔵の警戒値+/夜の密談イベントが敵対化** |
| 転嫁B | 「藤乃姉さんも起きていたはず」 | △ 無実の者への転嫁。確信度-10だが「良心」低下+藤乃との関係悪化 |

> **設計意図**:正解が複数あり、それぞれ**後日の人間関係にツケが回る**ことを見せる。1日目の何気ない選択(厨房手伝い)が弾になる快感の初提示。

---

### ◆ N3「カップに残った、あんたの指紋」

| 選択 | 手札/内容 | 結果 |
|---|---|---|
| **反証A ◎** | カード【食後の後片付け】(0日目宴の席で「片付けを手伝う」選択済なら自動入手) | ○ 正解。「宴の後、全員分のカップを私が下げました。指紋が付くのは当然です」→鎖完全破壊 |
| 反証B | 「手袋をしていれば指紋など――」 | **☠ 大失点**。「ほう、犯人の手口に詳しいんだな?」確信度+20、疑惑+10 |
| 沈黙 | ― | △ N2を砕いていれば小五郎が自壊(「うーむ、運んだのが別人なら指紋の意味も…」)。N2未破壊なら確信度+15 |

---

### ◆ 幕間:コナンの割り込み(証言ログのチュートリアル)

尋問が緩んだ隙に、コナンが無邪気な顔で:

> コナン「ねえお姉さん、おとといの夜って、何時ごろお部屋に戻ったのー?」

| 選択 | 結果 |
|---|---|
| 「11時前には」 | 0日目に蘭へ話した内容と一致していれば安全。**矛盾していれば証言ログに赤フラグ**(この場では何も起きないが、3日目の推理ショーで突きつけられる) |
| 「覚えていないわ」 | 安全だが、コナンのメモに「曖昧な返答」記録 |
| 「どうしてそんなことを聞くの?」 | 質問返し。疑惑+5だが、コナンの注目対象を推定できる情報が返る |

> **設計意図**:プレイヤーの過去の発言がすべて記録され、後で照合されるシステムの顔見せ。「この子供は議事録である」という恐怖の植え付け。

## リザルト分岐

| 終了時の確信度 | 結果 |
|---|---|
| 〜30% | **完封**。「疑って悪かったな」。3日目推理ショーの初期確信度が低く始まる+夕食で蘭との好感イベント |
| 31〜69% | **保留**。「まあ、今の段階ではな…」。標準継続 |
| 70%〜 | **要注意人物化**。以後、自由行動時にコナンの尾行イベントが発生(行動によっては撒ける)。3日目が高難度に |
| 知りすぎ判定2回 | 確信度に関わらず**コナン個別マーク**。夜、廊下で待ち伏せイベント「お姉さん、少しだけいい?」が強制発生(第三章の二択演出に接続) |

## このパートで教えたい3原則(デザインノート)

1. **真実は最強の毒**:知っていることを言えば言うほど死ぬ。倒叙の緊張=沈黙の技術
2. **弾は日常で拾う**:配膳メモも片付けの記憶も、選択の副産物。以後の自由行動の重みづけが変わる
3. **論破の代償**:転嫁で勝つたび、人間関係と「良心」が削れる。勝ち方が結末(特に告白ルートの色)を規定する
