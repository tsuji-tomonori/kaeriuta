# 帰り唄 ―手毬唄の館― α版

## すぐ遊ぶ

インストール不要で、[公開版](https://tsuji-tomonori.github.io/kaeriuta/)をブラウザで開けばすぐに遊べます。

セーブデータはブラウザのlocalStorageに保存されるため、利用したブラウザ・端末ごとに保持されます。ブラウザのサイトデータを削除した場合や別のブラウザ・端末では引き継がれません。

タイトルからプロローグ〜全4章・7ENDまで通して遊べる倒叙ミステリーアドベンチャーです。反論、共同推理、自由行動、手毬唄ボード、証言ログに加え、3枠セーブ、章選択、回想モード、手帳、バックログ、既読スキップ、オート送りを収録しています。

## 開発者向け: ローカル起動と操作

リポジトリ直下で実行し、ブラウザで `http://localhost:8000/` を開きます。

```sh
python3 -m http.server 8000
```

特殊パート中もセーブできます。ロード時はその特殊パートの開始時点から再開します。

## 操作方法

- クリック／Space／Enter: メッセージを送る（文字表示中は全文表示）
- Ctrl: 既読スキップの開始・停止
- S: セーブ
- A: オート送りの開始・停止
- L: ロード
- N: 手帳を開閉
- ゲーム中の「設定」: テキスト速度、オート待ち時間、スキップ範囲、BGM／SE音量、ミュート、自由探索の事前ヒントを変更
- Esc: 開いているメニュー、手帳、バックログを閉じる
- ホイール上: バックログを開く

選択肢はクリックで選びます。メニューや手帳、バックログ、確認ダイアログを開いている間は、ゲーム本文の送りは発生しません。

## α版の範囲

- 実装済み: プロローグ〜第四章、A-1〜A-4／B-1〜B-3、反論・共同推理・館の見取り図による自由探索・手毬唄ボード・証言ログ、3枠セーブとオートセーブ（特殊パート開始時点からの再開を含む）、章選択、回想モード、手帳、バックログ、既読スキップ、オート送り、ゲーム中のプレイ設定変更、BGM・効果音、起動時のローディング表示、欠落アセット用Canvasプレースホルダ
- 未実装・継続中: 画像・表情差分の拡充

## 検証コマンド

```sh
node --test
node tools/シナリオ検証.mjs
node tools/統合検証.mjs
node tools/到達可能性検査.mjs
node tools/END到達条件検査.mjs
tools/音源生成.sh
tools/構文検査.sh
tools/ブラウザ検証/実行.sh
tools/AIプレイ/実行.sh all
python3 tools/透過検品.py
python3 tools/構図検査.py
```

- `node --test`: エンジン・条件・特殊パート等のユニットテストを実行する。
- `tools/シナリオ検証.mjs`: シーン、ラベル、条件、ID、特殊パート呼出し、END本文の参照整合を静的検証する。
- `tools/統合検証.mjs`: シーン遷移と全7ENDの定義、manifest欠落時のプレースホルダ継続を検証する。
- `tools/到達可能性検査.mjs`: 代表経路をデータ直読でたどる補助検査（実プレイではない）。
- `tools/END到達条件検査.mjs`: 第一章4/6・第二章4/5の予算で全7ENDの具体的到達経路を探索する。
- `tools/音源生成.sh`: lavfi音源を再生成し、音量を実測して基準内であることを検査する。
- `tools/構文検査.sh`: `src`、AIプレイ、ブラウザ検証のブラウザ用JSをESMとして構文検査する。
- `tools/ブラウザ検証/実行.sh`: 実ブラウザで代表ルートを自動操作し、例外・停止・オーバーフローを記録する。
- `tools/AIプレイ/実行.sh all`: 9ペルソナで実ブラウザを通し、判断理由・END・最終状態をログ化する。
- `tools/透過検品.py`: 立ち絵のRGBA、輪郭マゼンタ、内側アルファ、完全不透明率を検査する。
- `tools/構図検査.py`: 立ち絵の頭部比率・頭上余白などの構図の揃いを検査する。

実ブラウザ系はChromeを起動するため、実行可能な環境でのみ利用してください。詳しいブラウザ検証の結果形式は [tools/ブラウザ検証/README.md](tools/ブラウザ検証/README.md) を参照してください。

## 構成

- `src/engine/`: 状態、条件、保存、アセット、音声のコア
- `src/ui/`: 1280×720・16:9レターボックスのUI
- `src/data/`: 人物、フラグ、証拠、唄、シナリオデータ
- `src/systems/`: 反論、共同推理、自由行動、手毬唄ボード、証言ログ
